## ✧ Engineering skills

- **Architecture:** Microservices, event-driven architecture, layered architecture, Hexagonal Architecture (Ports & Adapters), database per service.
- **Software design:** OOP, SOLID, GRASP, Dependency Injection, Repository, Factory, Composite, Decorator, Proxy and Adapter patterns.
- **Distributed systems:** Transactional Outbox, idempotent event processing, correlation IDs, gRPC timeouts, MongoDB Change Streams, rate limiting (sliding window), Redis TTL.
- **Data & backend:** CRUD, DTO mapping, input validation, SQL functions and indexes, schema migrations, soft delete, caching, RBAC and resource ownership checks.
- **Asynchronous programming:** `async/await`, `Task`, `CancellationToken`, `IAsyncEnumerable`, thread-safe collections, background services.
- **Testing:** Unit and integration testing, test doubles, isolation of business logic.
